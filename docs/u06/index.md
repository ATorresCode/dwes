# UD06. Acceso a bases de datos y CRUD

## Objetivos

- Conectar una aplicación web con una base de datos.
- Realizar operaciones CRUD sobre datos persistentes.
- Aplicar buenas prácticas de seguridad e integridad.

## Contenidos

- Conexión a MySQL con Node.js.
- Consultas SELECT, INSERT, UPDATE y DELETE.
- Manejo de errores y transacciones básicas.
- Publicación de datos desde el servidor en páginas web.

## Relación con los RA

- RA6: desarrollo de aplicaciones de acceso a almacenes de datos.
- RA4 y RA5: integración con sesiones, formularios y arquitectura organizada.
