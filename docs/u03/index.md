# UD03. Generación dinámica y plantillas

## Objetivos

- Generar contenido dinámico desde el servidor.
- Integrar código en lenguajes de marcas mediante plantillas.
- Diferenciar entre renderizado del servidor y lógica en cliente.

## Contenidos

- Respuesta HTML desde Express.
- Motores de plantillas: EJS o Handlebars.
- Variables, condiciones y bucles en plantillas.
- Formularios y envío de datos.

## Relación con los RA

- RA2 y RA8: generación dinámica de páginas y uso de tecnologías del servidor.
- RA3: uso de estructuras de programación dentro de la lógica de presentación.
