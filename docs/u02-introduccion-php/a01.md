# Actividades de PHP

## Actividad 1: DAW SHOP v2.0 · ★☆☆☆☆

Desarrollar una versión de la tienda DAW SHOP reutilizando código modular mediante PHP (`include` o `require`) para separar la cabecera, el pie y el menú de navegación en una estructura de carpetas organizada.

## Actividad 2: Ficha personal · ★☆☆☆☆

Crear un script PHP llamado `personalDataTuNombre.php` que contenga un array asociativo con los datos de una persona (nombre, apellidos, email, fecha de nacimiento y número de teléfono) y los muestre en forma de tabla HTML estructurada.

## Actividad 3: Personas · ★★☆☆☆

Crear un script PHP llamado `peopleTuNombre.php` que contenga un array bidimensional con los datos de 5 personas (nombre, altura y email), donde cada persona es un array asociativo. Recorrer el array y mostrarlo en una tabla HTML.

## Actividad 4: Calculando · ★★☆☆☆

Crear un script PHP llamado `calcTuNombre.php` que almacene dos números en sendas variables y muestre las operaciones básicas (suma, resta, multiplicación, división y módulo). Además, debe indicar cuál es mayor (o si son iguales) y determinar para cada uno si es par o impar (sin utilizar funciones).

## Actividad 5: Analizando una frase · ★★★☆☆

Crear un script PHP llamado `stringsTuNombre.php` con una frase predefinida extensa. Utilizar funciones de cadena de PHP para mostrar:

* La frase invertida.
* La posición de la palabra "cifras".
* El texto posterior a la palabra "cabo".
* La cantidad de veces que aparece la palabra "de".

## Actividad 6: Las tablas de multiplicar · ★★★☆☆

Crear un script PHP llamado `tableTuNombre.php` que muestre una tabla de multiplicar completa de $10 \times 10$ utilizando bucles anidados y condiciones para dar formato a las celdas de cabecera y contenido.

## Actividad 7: Ordenando datos · ★★★★☆

Crear un script PHP llamado `sortingArrayTuNombre.php`. Se debe inicializar un array de 10 números enteros, mostrarlo, ordenarlo aplicando el algoritmo de **ordenación por selección** de forma manual (sin usar funciones preordenadas de PHP) y volver a mostrar el resultado ordenado.

## Actividad 8: Generando HTML · ★★★★★

Crear un script PHP llamado `generatingTuNOMBRE.php` que genere dinámicamente:

* Una lista desordenada de 5 elementos con enlaces internos a secciones (`#sec1` a `#sec5`).
* Un contenedor `<section>` con 5 elementos `<article>`, cada uno con un ID de sección y un título `<h1>`.
* Contenido dinámico específico por sección:
  * `sec1`: Evaluar si un número aleatorio entre $-200$ y $200$ es negativo, cero o positivo.
  * `sec2`: Evaluar una nota entera aleatoria del $0$ al $10$ usando `switch` para mostrar su calificación textual (desde insuficiente hasta sobresaliente).
  * `sec3`: Generar la tabla de multiplicar de un número aleatorio del $0$ al $100$ (del $0$ al $20$) en formato HTML.
  * `sec4`: Crear una tabla HTML bidimensional cuyas dimensiones (filas y columnas) vengan dadas por dos números aleatorios, rellenando cada celda con sus coordenadas (ej. `0x0`).
  * `sec5`: Descomponer un número aleatorio entre $1$ y $1000$ en el mínimo número de billetes ($500, 200, 100, 50, 20, 10, 5$) y monedas ($2, 1$) **sin utilizar estructuras de control** (ni `if`, ni `switch`, ni bucles), permitiendo únicamente operadores aritméticos y la función `intval($dividendo/$divisor)`.

## Actividad 9: Calculando v2.0 · ★★★★★

Tomando como base la actividad de cálculo, crear un fichero de funciones llamado `funcionesTuNombre.php` que contenga 7 funciones independientes para sumar, restar, multiplicar, dividir, calcular módulo, comprobar igualdad y verificar si un número es par. Este archivo no contiene HTML y debe ser probado en colaboración con un compañero de clase que integre dichas funciones en su propio script.

## Actividad 10: Juegos de cartas (Higher & Blackjack) · ★★★★★

Desarrollar una aplicación web estructurada en varios scripts (`index.php`, `getdeck.php`, `highertutombre.php` y `blackjacktunombre.php`):

* `getdeck.php`: Contiene una función que genera y devuelve un array asociativo completo de la baraja francesa (52 cartas + 2 comodines) con sus palos, valores y rutas de imagen normalizadas.
* `index.php`: Página de bienvenida con cabecera y pie compartidos que incluye información de la aplicación.
* `higherTuNombre.php`: Juego de cartas donde se reparten 10 cartas a dos jugadores y se comparan una a una aplicando reglas de puntuación específicas para comodines, cartas iguales o superiores, mostrando avatares y estilos condicionales.
* `blackjackTuNombre.php`: Simulación de Blackjack con 5 jugadores y la banca, extrayendo comodines, aplicando reglas de puntuación de la baraja (A, J, Q, K), lógica de extracción automática de cartas si la suma es menor a 14, y comprobación de victoria/derrota frente a la banca.
