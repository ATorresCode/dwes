# Actividades de refuerzo de PHP

## Actividad 1: Hola Mundo con funciones · ★☆☆☆☆

Realizar un script PHP sencillo que utilice una función para mostrar por pantalla el texto "Hola mundo".

## Actividad 2: Lista desordenada numérica · ★☆☆☆☆

Realizar un script PHP que muestre todos los números enteros del 1 al 10 estructurados dentro de una lista desordenada HTML.

## Actividad 3: Múltiplo de 3 · ★★☆☆☆

Realizar un script PHP que genere un número aleatorio mediante funciones nativas de PHP e indique mediante una condición si dicho número es múltiplo de 3 o no.

## Actividad 4: Conversor a binario predefinido · ★★☆☆☆

Realizar un script PHP que, dado un número decimal, muestre su equivalente en código binario utilizando las funciones predefinidas del lenguaje.

## Actividad 5: Identificador de tipos de datos · ★★☆☆☆

Crear un script PHP que asigne diversos tipos de valores a una variable (enteros, cadenas, booleanos, floats, arrays) y utilice funciones de inspección para indicar el tipo de dato exacto almacenado en cada momento.

## Actividad 6: Simulación de tirada de dados de rol · ★★★☆☆

Simular la tirada de dados típica de un juego de rol. Mostrar la imagen correspondiente a cada dado junto con el valor aleatorio obtenido debajo. Los dados serán de 4, 6, 8, 10, 12 y 20 caras; el dado de 10 caras debe tirarse y mostrarse dos veces.

## Actividad 7: Eliminación de espacios en frases · ★★★☆☆

A partir de una cadena de texto o frase dada, procesarla mediante funciones de manipulación de cadenas de PHP para mostrarla completamente sin espacios en blanco.

## Actividad 8: Análisis de vocales en una frase · ★★★☆☆

A partir de una frase de entrada, analizar el contenido para calcular y mostrar la cantidad exacta de apariciones de cada vocal, así como el total de vocales encontradas.

## Actividad 9: Array aleatorio básico · ★★★☆☆

Rellenar un array con 50 números enteros aleatorios comprendidos entre el 0 y el 99 usando `rand(0, 99)`, y recorrerlo para mostrarlo en una lista desordenada HTML.

## Actividad 10: Array asociativo básico (`$persona`) · ★★★☆☆

Crear un array asociativo llamado `$persona` que contenga la información de nombre, edad y ciudad, y mostrar su contenido de manera legible y estructurada en texto plano o HTML.

## Actividad 11: Modificación de array asociativo · ★★★☆☆

Tomando como base el array `$persona` de la actividad anterior, modificar la edad y añadir una nueva clave llamada "ocupación". Volver a mostrar el contenido actualizado de forma legible.

## Actividad 12: Conteo de caracteres con arrays asociativos · ★★★★☆

Rellenar un array de 100 elementos aleatoriamente con valores `'M'` o `'F'`. Recorrerlo para calcular cuántos elementos hay de cada categoría y almacenar el recuento en un array asociativo, **sin utilizar variables contadoras manuales**.

## Actividad 13: Filtrado de calificaciones de alumnos · ★★★★☆

1. Crear un array asociativo de 10 alumnos con sus respectivas calificaciones decimales.
2. Diseñar una función que reciba dicho array y una nota de corte, y devuelva un **nuevo array** con los alumnos que alcancen o superen dicha nota.

## Actividad 14: Estructuras complejas de alumnos y notas · ★★★★★

1. Crear un array asociativo multidimensional con la información de 5 alumnos y sus calificaciones por asignatura.
2. Mostrar la información completa mediante una tabla HTML legible.
3. Mostrar dinámicamente **qué alumno ha obtenido la nota más alta en cada asignatura**.
