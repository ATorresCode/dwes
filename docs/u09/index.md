# UD09. Proyecto final y despliegue

## Objetivos

- Integrar todos los conocimientos del módulo en un proyecto completo.
- Desarrollar una aplicación web funcional con backend, base de datos y cliente.
- Documentar, probar y presentar el proyecto final.

## Contenidos

- Planificación del proyecto.
- Implementación de CRUD, autenticación y servicios.
- Uso de GitHub Copilot para apoyar el desarrollo, con explicación y defensa del código.
- Despliegue básico y presentación final.

## Relación con los RA

- Consolidación de todos los resultados de aprendizaje del módulo.
- Preparación para la evaluación final y para entornos profesionales reales.
