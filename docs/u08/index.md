# UD08. Integración con cliente y aplicaciones híbridas

## Objetivos

- Integrar el backend con una interfaz en React.
- Consumir APIs REST desde el cliente.
- Reutilizar información y librerías externas en una aplicación web híbrida.

## Contenidos

- Comunicación frontend-backend con fetch o axios.
- Gestión de datos en React y despliegue de peticiones al servidor.
- Consumo de APIs públicas y repositorios de información.
- Integración de componentes reutilizables.

## Relación con los RA

- RA8: generación dinámica y trabajo conjunto con cliente y servidor.
- RA9: aplicaciones híbridas y reutilización de código e información.
