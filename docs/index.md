# Desarrollo Web en Entorno Servidor

Bienvenido al módulo de Desarrollo Web en Entorno Servidor (DWES).

## Propuesta de estructura del módulo

Esta propuesta adapta el currículo oficial de 2010 a un enfoque profesional y actual, partiendo de un entorno basado en Node.js, Express, React y MySQL. El objetivo es que los alumnos aprendan los resultados de aprendizaje del módulo mientras trabajan con tecnologías que tienen un uso real en el entorno profesional de 2026.

## Enfoque pedagógico

- Se prioriza JavaScript en cliente y servidor para aprovechar el conocimiento previo de los alumnos.
- Se introduce una base sólida de programación en servidor, formularios, sesiones, autenticación, bases de datos y servicios web.
- Se incorpora GitHub Copilot como apoyo para aprender a programar con IA, siempre con una evaluación basada en la comprensión real del código.
- El módulo acaba con un proyecto final que integra frontend, backend, base de datos y documentación.
