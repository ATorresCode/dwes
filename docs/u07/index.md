# UD07. Servicios Web y APIs REST

## Objetivos

- Comprender el funcionamiento de los servicios web y las APIs REST.
- Diseñar y publicar endpoints para consumir desde un cliente.
- Documentar y probar APIs de forma básica.

## Contenidos

- Conceptos de API REST y recursos.
- Métodos HTTP: GET, POST, PUT y DELETE.
- Documentación con Swagger o OpenAPI.
- Consumo de servicios desde el cliente y desde herramientas como Postman o Thunder Client.

## Relación con los RA

- RA7: desarrollo de servicios web y documentación.
- RA8 y RA9: integración con aplicaciones web híbridas y consumo de recursos externos.
