# UD02. Fundamentos de programación en servidor

## Objetivos

- Entender la sintaxis básica de JavaScript en el servidor.
- Escribir sentencias simples, variables, operadores y estructuras de control.
- Comprender el flujo de una petición HTTP en Express.

## Contenidos

- Variables, tipos de datos y operadores.
- Estructuras de decisión y bucles.
- Funciones y módulos.
- Primeros endpoints con Express.

## Relación con los RA

- RA2: escribir sentencias ejecutables por un servidor web.
- RA3: trabajar con estructuras de programación y funciones.
