# UD03: Programación Orientada a Objetos con PHP

La Programación Orientada a Objetos (POO) es un paradigma que organiza un programa mediante objetos. Cada objeto agrupa un estado (sus datos) y un comportamiento (las operaciones que puede realizar). En PHP, los objetos se crean a partir de clases.

## Objetivos

- Comprender los conceptos básicos de la POO.
- Declarar clases y crear objetos en PHP.
- Inicializar objetos con constructores y trabajar con sus propiedades y métodos.
- Aplicar encapsulación mediante modificadores de acceso.
- Conocer los métodos mágicos y cuándo conviene utilizarlos.
- Declarar miembros estáticos.
- Distinguir referencias, copias e identidad de objetos.
- Gestionar errores mediante excepciones.

---

## 1. Introducción a la Programación Orientada a Objetos

El concepto de POO apareció con el lenguaje **Simula**, cuyo desarrollo comenzó en 1962 y que se publicó en 1967. La popularización de lenguajes como **Java** (1995) y **C#** (2000) extendió el uso de este paradigma.

En POO los elementos del programa se modelan como objetos que representan conceptos o entidades. Por ejemplo, en una tienda puede haber objetos `Product`, `Customer` y `Order`.

### Ventajas de la POO

- **Modularidad**: permite dividir un programa en partes más pequeñas, con responsabilidades diferenciadas.
- **Reutilización y extensibilidad**: facilita reutilizar y ampliar funcionalidad, por ejemplo, mediante herencia o composición.
- **Mantenimiento**: un diseño modular facilita localizar y modificar el código relacionado con una funcionalidad.

### Características principales

#### Abstracción

Una clase ofrece las operaciones necesarias para utilizar un objeto sin obligar a conocer sus detalles internos.

#### Encapsulación

Agrupa datos y operaciones relacionadas y permite controlar cómo se accede al estado del objeto.

#### Herencia

Permite definir una clase nueva a partir de otra y reutilizar o especializar parte de su comportamiento. Se desarrolla en [r02.md](./r02.md).

#### Polimorfismo

Permite utilizar objetos de tipos relacionados a través de una operación común y que cada tipo proporcione su comportamiento concreto. Las interfaces y las clases abstractas se estudian en [r02.md](./r02.md).

> **Nota:** la sobrecarga de métodos, en la que se definen varias versiones de un método según sus parámetros, no está soportada como tal en PHP. Se puede resolver eligiendo argumentos opcionales, argumentos con nombre o argumentos variables.

### Clases y objetos

- **Clase**: plantilla que describe los datos y las operaciones de un tipo de objeto.
- **Propiedad** o **atributo**: dato que forma parte del estado de un objeto. Dos objetos de la misma clase pueden tener valores distintos.
- **Método**: operación que puede realizar un objeto. Puede recibir parámetros y devolver un resultado.
- **Objeto**: instancia concreta de una clase.

Por ejemplo, `Product` puede ser una clase, `$ps5` un objeto de esa clase, `name` una propiedad y `data()` un método.

## 2. POO en PHP

PHP incorporó progresivamente las características de la POO:

| Versión | Evolución |
| --- | --- |
| PHP 3 | Introdujo algunos conceptos de POO. |
| PHP 4 | Potenció su uso. |
| PHP 5 | Incorporó un modelo de objetos renovado. |
| PHP actual | Ofrece soporte amplio para POO; no admite herencia múltiple de clases ni sobrecarga tradicional de métodos. |

PHP permite crear jerarquías con herencia simple, implementar varias interfaces y reutilizar código con *traits*. Estos conceptos se explican en [r02.md](./r02.md).

## 3. Clases y objetos en PHP

Se declara una clase con la palabra reservada `class`. Como convención, el nombre de la clase empieza por mayúscula y cada clase se guarda en un archivo propio, por ejemplo `Product.php`.

```php
<?php

class Product
{
    public $code;
    public $name;
    public $price;

    public function __construct($code = '', $name = '', $price = 0.0)
    {
        $this->code = $code;
        $this->name = $name;
        $this->price = $price;
    }

    public function data()
    {
        return $this->name . ' (' . $this->code . '): ' . $this->price . ' €';
    }
}
```

En el interior de un objeto, `$this` representa el objeto actual. Se utiliza `->` para acceder a sus propiedades y métodos:

```php
$this->name;
$this->data();
```

Desde otro lugar del programa también se usa `->`:

```php
$product->name;
$product->data();
```

No se utiliza el punto (`.`) para acceder a miembros; en PHP el punto sirve para concatenar cadenas.

### Incluir la clase e instanciar objetos

Para utilizar una clase definida en otro archivo, se puede incluir con `require_once`. `__DIR__` hace que la ruta sea relativa al archivo que contiene la instrucción:

```php
<?php

require_once __DIR__ . '/Product.php';

$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$tvSamsung = new Product('samsung-65', 'Samsung 65 pulgadas');
$iphone = new Product(name: 'Apple iPhone 14', price: 1009.0);
$tablet = new Product(name: 'Galaxy Tab');

echo $ps5->data();
```

La palabra `new` crea un objeto. Los argumentos con nombre, disponibles desde PHP 8, permiten indicar qué parámetro se quiere asignar sin escribir los anteriores.

En el ejemplo, el constructor tiene valores por defecto, por lo que se pueden omitir argumentos. Para definir distintas formas de creación en PHP se suele recurrir a parámetros opcionales, argumentos con nombre o métodos de creación; no se pueden declarar varios constructores con diferentes firmas.

### Convenciones de organización

Una organización habitual de una clase es:

1. Propiedades.
2. Constructor.
3. Métodos públicos y privados agrupados según su responsabilidad.

La convención tradicional de los materiales de clase utiliza nombres como `Product.inc.php`; en proyectos actuales es frecuente usar `Product.php` y cargar las clases mediante autoloaders.

## 4. Propiedades, métodos y encapsulación

Los modificadores de acceso controlan desde dónde se puede utilizar una propiedad o un método:

| Modificador | Acceso |
| --- | --- |
| `public` | Desde cualquier lugar donde el objeto o la clase sea accesible. |
| `protected` | Desde la clase que lo declara y sus subclases. |
| `private` | Solo desde la clase que lo declara. |

Si una propiedad es `public`, se puede leer y modificar directamente:

```php
$ps5->name = 'PlayStation 5';
echo $ps5->name;
```

Si la propiedad es `private`, el acceso directo desde fuera de la clase produce un error:

```php
class Product
{
    private $name;
}

$product = new Product();
$product->name = 'PlayStation 5'; // Error: name es privada.
```

Normalmente se mantienen las propiedades privadas y se ofrecen métodos públicos que controlan la lectura o modificación del estado. A estos métodos se les suele llamar **getters** y **setters**.

```php
<?php

class Product
{
    private string $code;
    private string $name;
    private float $price;

    public function __construct(
        string $code = '',
        string $name = '',
        float $price = 0.0
    ) {
        $this->code = $code;
        $this->name = $name;
        $this->price = $price;
    }

    public function getCode(): string
    {
        return $this->code;
    }

    public function setCode(string $code): void
    {
        $this->code = $code;
    }

    public function getName(): string
    {
        return $this->name;
    }

    public function setName(string $name): void
    {
        $this->name = $name;
    }

    public function getPrice(): float
    {
        return $this->price;
    }

    public function setPrice(float $price): void
    {
        if ($price < 0) {
            throw new InvalidArgumentException('El precio no puede ser negativo.');
        }

        $this->price = $price;
    }

    public function data(): string
    {
        return $this->name . ' (' . $this->code . '): ' . $this->price . ' €';
    }
}
```

El setter permite validar el dato antes de guardarlo. Así, la clase protege sus propias reglas en lugar de depender de que cada parte del programa las aplique correctamente.

```php
$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$ps5->setCode('sony-PS5');

echo $ps5->getCode();
echo $ps5->data();
```

Los tipos de propiedades, parámetros y retornos hacen el contrato de la clase más claro y ayudan a detectar errores. Los tipos `string`, `int`, `float` y `bool` son ejemplos habituales.

## 5. Constructores y ciclo de vida

El constructor se ejecuta al crear el objeto y se declara como `__construct()`.

```php
class User
{
    private string $name;

    public function __construct(string $name)
    {
        $this->name = $name;
    }
}

$user = new User('Ada');
```

PHP permite un único método constructor por clase. Si hacen falta valores alternativos, se pueden definir parámetros con valores por defecto:

```php
public function __construct(
    string $code = '',
    string $name = '',
    float $price = 0.0
) {
    $this->code = $code;
    $this->name = $name;
    $this->price = $price;
}
```

El destructor `__destruct()` se invoca cuando el objeto deja de tener referencias o durante la finalización del proceso. No suele ser necesario definirlo para el código habitual; los recursos que requieren cierre explícito deben gestionarse de forma clara y predecible.

## 6. Métodos mágicos

Los **métodos mágicos** son métodos especiales que PHP llama en determinadas situaciones. Sus nombres comienzan con dos guiones bajos (`__`). Entre ellos están:

| Método | Cuándo se utiliza |
| --- | --- |
| `__construct()` | Al crear un objeto. |
| `__destruct()` | Al destruir un objeto. |
| `__get()` y `__set()` | Al leer o escribir una propiedad inaccesible o inexistente. |
| `__isset()` y `__unset()` | Al aplicar `isset()` o `unset()` a una propiedad inaccesible o inexistente. |
| `__call()` y `__callStatic()` | Al invocar un método inaccesible o inexistente. |
| `__toString()` | Al convertir un objeto a texto. |
| `__invoke()` | Al invocar el objeto como si fuera una función. |
| `__clone()` | Al clonar un objeto. |
| `__serialize()` y `__unserialize()` | Al serializar y deserializar un objeto. |
| `__sleep()` y `__wakeup()` | Hooks del mecanismo tradicional de serialización. |
| `__set_state()` | Al reconstruir un objeto mediante `var_export()`. |
| `__debugInfo()` | Al mostrar información del objeto con `var_dump()`. |

No conviene utilizarlos solo para reducir líneas de código: pueden hacer menos evidente qué operaciones ejecuta una expresión y requieren cuidado con las validaciones.

### Ejemplo de `__get()` y `__set()`

`__get()` recibe como argumento el nombre de la propiedad que se intenta leer; `__set()` recibe ese nombre y el valor que se quiere asignar. Una implementación debe permitir únicamente propiedades conocidas y aplicar las reglas necesarias:

```php
<?php

class Product
{
    private string $code;
    private string $name;
    private float $price;

    public function __construct(string $code, string $name, float $price)
    {
        $this->code = $code;
        $this->name = $name;
        $this->price = $price;
    }

    public function __get(string $property): mixed
    {
        if (!property_exists($this, $property)) {
            throw new InvalidArgumentException("Propiedad desconocida: $property");
        }

        return $this->$property;
    }

    public function __set(string $property, mixed $value): void
    {
        if (!property_exists($this, $property)) {
            throw new InvalidArgumentException("Propiedad desconocida: $property");
        }

        if ($property === 'price') {
            if (!is_numeric($value) || (float) $value < 0) {
                throw new InvalidArgumentException('El precio no es válido.');
            }

            $value = (float) $value;
        } elseif (!is_string($value)) {
            throw new InvalidArgumentException('El valor debe ser una cadena.');
        }

        $this->$property = $value;
    }
}

$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$ps5->name = 'PlayStation 5';
echo $ps5->name;
```

En este ejemplo, `property_exists()` impide que se creen propiedades dinámicas por error y el setter conserva los tipos y reglas de los datos. En PHP 8.2, crear propiedades dinámicas en clases que no lo permiten expresamente está obsoleto. Para la mayoría de clases, getters y setters explícitos suelen ser más fáciles de validar y mantener que un `__get()` o `__set()` genérico.

> **Tipado de métodos mágicos:** al declarar sus parámetros y valores de retorno, hay que respetar las firmas que espera PHP para cada método. `__get()` debe devolver `mixed`; `__set()` no devuelve un valor.

### Ejemplo de `__toString()`

`__toString()` define la representación textual de un objeto:

```php
public function __toString(): string
{
    return $this->name . ' (' . $this->code . ')';
}
```

Así se podría escribir:

```php
echo $product;
```

Es mejor reservarlo para una representación textual sencilla. No conviene convertirlo en una plantilla de presentación ni mezclar en él la lógica de negocio.

## 7. Propiedades y métodos estáticos

Un miembro `static` pertenece a la clase, no a una instancia concreta. Se accede con el operador de ámbito `::`. Dentro de la propia clase se suele utilizar `self::`.

```php
<?php

class Product
{
    private static int $quantityOfProducts = 0;
    public static bool $existsAnyProduct = false;

    public function __construct(
        private string $code,
        private string $name,
        private float $price
    ) {
        self::$quantityOfProducts++;
        self::$existsAnyProduct = true;
    }

    public static function getQuantityOfProducts(): int
    {
        return self::$quantityOfProducts;
    }
}

$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$tablet = new Product('galaxy-tab', 'Galaxy Tab', 399.0);

echo Product::getQuantityOfProducts(); // 2
echo Product::$existsAnyProduct;       // true
```

Los miembros estáticos pueden ser útiles para operaciones o datos compartidos por la clase. No tienen acceso a `$this`, porque no se ejecutan sobre una instancia concreta.

```php
class Math
{
    public static function sum(int $a, int $b): int
    {
        return $a + $b;
    }
}

echo Math::sum(4, 6); // 10
```

No se debe convertir automáticamente cualquier estado en estático: compartir estado entre objetos puede dificultar las pruebas y el mantenimiento.

## 8. Trabajo con objetos

### Comprobar el tipo

El operador `instanceof` comprueba si un objeto pertenece a una clase o a un tipo compatible:

```php
if ($product instanceof Product) {
    echo 'Es un Product';
}
```

También se pueden consultar, entre otras, estas funciones:

| Función | Uso |
| --- | --- |
| `get_class($object)` | Obtiene el nombre de la clase del objeto. |
| `class_exists('Product')` | Comprueba si una clase está definida o disponible mediante autoload. |
| `get_class_methods($object)` | Devuelve los nombres de los métodos accesibles de una clase. |
| `property_exists($object, 'name')` | Comprueba si una propiedad está declarada en la clase o el objeto. |

### Referencias y asignación

Al asignar una variable que contiene un objeto a otra variable, ambas permiten acceder al mismo objeto:

```php
$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$sameProduct = $ps5;

$sameProduct->setName('PlayStation 5');
echo $ps5->getName(); // PlayStation 5
```

La asignación no crea un segundo objeto independiente. Por eso, los cambios realizados a través de una variable también se observan al utilizar la otra.

### Clonar un objeto

Para crear un objeto distinto con los mismos valores iniciales se utiliza `clone`:

```php
$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$copy = clone $ps5;

$copy->setName('PlayStation 5 Slim');
echo $ps5->getName(); // PS5
echo $copy->getName(); // PlayStation 5 Slim
```

La clonación es superficial: si el objeto contiene propiedades que a su vez son objetos, la copia conserva las referencias a esos objetos internos, salvo que se implemente la lógica necesaria en `__clone()`.

### Comparar objetos

- `==` comprueba si los objetos son instancias de la misma clase y tienen los mismos valores de propiedades.
- `===` comprueba si ambas variables apuntan a la misma instancia.

```php
$ps5 = new Product('sony-ps5', 'PS5', 499.99);
$copy = clone $ps5;
$sameProduct = $ps5;

var_dump($ps5 == $copy);         // true: mismos valores
var_dump($ps5 === $copy);        // false: objetos distintos
var_dump($ps5 === $sameProduct); // true: misma instancia
```

## 9. Excepciones

Las excepciones representan situaciones que impiden completar una operación de la forma habitual. PHP utiliza los bloques `try`, `catch` y, de manera opcional, `finally`.

- `try`: contiene el código que puede lanzar una excepción.
- `catch`: recibe y gestiona una excepción de un tipo determinado.
- `finally`: se ejecuta tanto si se produce una excepción como si no.

Un bloque `try` debe tener al menos un `catch` o un `finally`; puede tener varios `catch`.

### Lanzar y capturar una excepción

```php
try {
    throw new Exception('Se ha producido un error.');
} catch (Exception $exception) {
    echo $exception->getMessage();
}
```

Para indicar que no se puede continuar con una operación, se lanza una excepción con `throw`:

```php
function divide(int $dividend, int $divisor): int
{
    if ($divisor === 0) {
        throw new InvalidArgumentException('El divisor no puede ser cero.');
    }

    return intdiv($dividend, $divisor);
}

try {
    echo divide(13, 0);
} catch (InvalidArgumentException $exception) {
    echo 'No se pudo realizar la operación: ' . $exception->getMessage();
}
```

También es posible capturar errores integrados de PHP. Por ejemplo, `intdiv(13, 0)` lanza `DivisionByZeroError`:

```php
try {
    $result = intdiv(13, 0);
} catch (DivisionByZeroError $exception) {
    echo 'Se ha producido un error: ' . $exception->getMessage();
}
```

### Bloque `finally`

```php
try {
    echo 'Comienza el proceso.';
} catch (Throwable $exception) {
    echo 'Se ha producido un error.';
} finally {
    echo ' Fin del proceso.';
}
```

`finally` se ejecuta al salir del bloque, tanto si el código termina correctamente como si se lanza una excepción. Resulta útil para liberar recursos; no debe ocultar la excepción original.

### Excepciones personalizadas

Se pueden definir excepciones propias heredando de `Exception`:

```php
class InvalidPriceException extends Exception
{
}

function validatePrice(float $price): void
{
    if ($price < 0) {
        throw new InvalidPriceException('El precio no puede ser negativo.');
    }
}

try {
    validatePrice(-10.0);
} catch (InvalidPriceException $exception) {
    echo $exception->getMessage();
}
```

## Resumen

- Una clase define propiedades y métodos; un objeto es una instancia de esa clase.
- El constructor `__construct()` inicializa el objeto.
- `->` accede a miembros de una instancia; `::` accede a miembros estáticos.
- `public`, `protected` y `private` regulan la visibilidad.
- La encapsulación protege el estado del objeto; getters y setters permiten exponer un acceso controlado.
- Los métodos mágicos responden a operaciones especiales y deben utilizarse con cuidado.
- La asignación de una variable de objeto no crea una copia; para clonar se utiliza `clone`.
- `==` compara valores y `===` identidad de la instancia.
- Las excepciones permiten propagar y gestionar errores de forma explícita.

En [r02.md](./r02.md) se amplía la unidad con herencia, sobrecarga, clases abstractas, interfaces y *traits*.
