# UD03: Programación Orientada a Objetos con PHP

La Programación Orientada a Objetos (POO) es un paradigma de programación que permite modelar aplicaciones mediante objetos que representan entidades del mundo real. En esta unidad se estudian los fundamentos de la POO y su implementación en PHP, incluyendo clases, objetos, propiedades, métodos, encapsulación, miembros estáticos y gestión de excepciones.

## Objetivos

- Comprender los principios fundamentales de la Programación Orientada a Objetos.
- Crear clases y objetos en PHP.
- Utilizar constructores, propiedades y métodos.
- Aplicar encapsulación mediante modificadores de acceso.
- Utilizar métodos mágicos de PHP.
- Declarar propiedades y métodos estáticos.
- Trabajar correctamente con referencias y copias de objetos.
- Gestionar errores mediante excepciones.

---

## 1. Introducción a la Programación Orientada a Objetos

La Programación Orientada a Objetos apareció con el lenguaje **Simula** en 1962 y fue popularizada posteriormente por lenguajes como **Java** y **C#**.

En la POO los elementos de un programa se modelan como objetos que representan entidades reales con:

- Características.
- Estado.
- Comportamiento.

Estos objetos se crean a partir de definiciones llamadas **clases**.

### Ventajas de la POO

- **Modularidad**: permite dividir una aplicación en partes independientes.
- **Extensibilidad**: facilita ampliar funcionalidades mediante herencia.
- **Mantenimiento**: favorece la reutilización y simplifica las modificaciones.

### Características principales

#### Herencia

Permite crear clases a partir de otras reutilizando propiedades y métodos.

#### Abstracción

Muestra únicamente la funcionalidad necesaria ocultando los detalles internos.

#### Polimorfismo

Permite utilizar una misma interfaz con comportamientos distintos.

#### Encapsulación

Agrupa datos y operaciones relacionadas dentro de una misma unidad.

---

## 2. Conceptos básicos de la POO

### Clases

Una clase es una plantilla que define las características y comportamientos de los objetos.

Está formada por:

- Propiedades o atributos.
- Métodos.

### Propiedades

Almacenan información sobre el estado del objeto.

### Métodos

Definen las acciones que puede realizar un objeto.

### Objetos e instancias

Cuando se crea un objeto a partir de una clase se dice que se ha creado una **instancia** de dicha clase.

---

## 3. POO en PHP

PHP no fue diseñado inicialmente para trabajar con orientación a objetos.

Su evolución ha sido:

| Versión | Características |
| ---------- | ---------- |
| PHP 3 | Primeros conceptos de POO |
| PHP 4 | Mejoras en orientación a objetos |
| PHP 5 | Nuevo modelo completo de objetos |
| PHP actual | Soporte completo para POO excepto herencia múltiple y sobrecarga de métodos |

---

## 4. Declaración de clases

Se recomienda almacenar cada clase en un archivo independiente.

```text
Product.inc.php
User.inc.php
Order.inc.php
```

Las clases se declaran utilizando la palabra reservada `class`.

```php
class Product
{
}
```

### Convenciones recomendadas

- El nombre de la clase comienza por mayúscula.
- Una clase por archivo.
- Primero propiedades.
- Después constructores.
- Finalmente métodos.

---

## 5. Acceso a propiedades y métodos

Para acceder a propiedades y métodos se utiliza el operador `->`.

```php
$product->getName();
$product->price;
```

Dentro de la propia clase se utiliza:

```php
$this->property
$this->method()
```

---

## 6. Constructores

El constructor permite inicializar un objeto cuando se crea.

Se define mediante:

```php
__construct()
```

Ejemplo:

```php
class Product
{
    private string $name;

    public function __construct(string $name)
    {
        $this->name = $name;
    }
}
```

Creación del objeto:

```php
$product = new Product('PlayStation 5');
```

Como PHP no soporta sobrecarga de constructores, se suelen utilizar parámetros opcionales.

---

## 7. Modificadores de acceso

PHP permite controlar el acceso a propiedades y métodos mediante:

| Modificador | Acceso |
| ------------ | --------- |
| public | Desde cualquier lugar |
| protected | Desde la clase y sus hijas |
| private | Solo desde la propia clase |

Ejemplo:

```php
class User
{
    private string $name;
}
```

### Getters y setters

Cuando las propiedades son privadas se utilizan métodos de acceso.

```php
public function getName(): string
{
    return $this->name;
}

public function setName(string $name): void
{
    $this->name = $name;
}
```

## 8. Métodos mágicos

PHP incorpora métodos especiales llamados **métodos mágicos**.

Todos comienzan por doble guion bajo:

```php
__construct()
__destruct()
__get()
__set()
__toString()
__clone()
```

Aunque proporcionan flexibilidad, suelen ser más lentos que los métodos convencionales.

### __get y __set

Permiten interceptar el acceso a propiedades.

```php
public function __get($property)
{
    return $this->$property;
}

public function __set($property, $value)
{
    $this->$property = $value;
}
```

### Precauciones

Desde PHP 8.2 la creación dinámica de propiedades está obsoleta.

Se recomienda comprobar que la propiedad existe:

```php
property_exists($this, $property)
```

### __toString

Permite indicar qué texto se mostrará al convertir un objeto a cadena.

```php
public function __toString(): string
{
    return $this->name;
}
```

No suele recomendarse mezclar la lógica de negocio con la presentación.

## 9. Propiedades y métodos estáticos

Los miembros estáticos pertenecen a la clase y no a los objetos.

Se declaran mediante:

```php
static
```

Ejemplo:

```php
class Math
{
    public static function sum(int $a, int $b): int
    {
        return $a + $b;
    }
}
```

Uso:

```php
echo Math::sum(4, 6);
```

### Acceso desde la propia clase

```php
self::method();
self::$property;
```

### Características

- No requieren instanciación.
- Son útiles para utilidades generales.
- Se accede mediante `::`.

## 10. Trabajo con objetos

### Comprobar el tipo de un objeto

Se utiliza el operador:

```php
instanceof
```

Ejemplo:

```php
if ($product instanceof Product) {
    echo 'Es un Product';
}
```

### Funciones útiles

PHP proporciona diversas funciones relacionadas con objetos:

```php
get_class()
class_exists()
get_class_methods()
```

La documentación oficial incluye muchas más utilidades.

## 11. Tipado en POO

Es recomendable indicar explícitamente los tipos:

```php
private string $name;

public function setName(string $name): void
{
    $this->name = $name;
}
```

Ventajas:

- Mayor claridad.
- Menos errores.
- Mejor soporte del IDE.

### Excepción

No se recomienda tipar los parámetros de:

```php
__get()
__set()
```

ya que podrían no funcionar correctamente.

---

## 12. Copias y referencias de objetos

Las variables que almacenan objetos guardan realmente una referencia al objeto.

```php
$product1 = new Product();
$product2 = $product1;
```

En este caso ambas variables apuntan al mismo objeto.

### Copia real de un objeto

Para crear un nuevo objeto idéntico se utiliza:

```php
$product2 = clone $product1;
```

---

## 13. Comparación de objetos

PHP dispone de dos operadores.

### Comparación de valores

```php
$product1 == $product2
```

Devuelve `true` si las propiedades contienen los mismos valores.

### Comparación de identidad

```php
$product1 === $product2
```

Devuelve `true` únicamente si ambas variables apuntan exactamente al mismo objeto.

## 14. Excepciones

Las excepciones permiten gestionar errores de forma controlada.

PHP utiliza:

```php
try
catch
finally
```

### Lanzar excepciones

```php
throw new Exception('Error');
```

### Capturar excepciones

```php
try {
    throw new Exception('Error');
} catch (Exception $exception) {
    echo $exception->getMessage();
}
```

### Bloque finally

```php
finally {
    echo 'Fin del proceso';
}
```

El bloque `finally` se ejecuta siempre, tanto si ocurre una excepción como si no.

### Excepciones personalizadas

También es posible crear excepciones propias heredando de `Exception`.

```php
class InvalidPriceException extends Exception
{
}
```
