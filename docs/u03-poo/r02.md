## 1. Herencia

La **herencia** permite definir una clase a partir de otra y crear una jerarquía. La clase que se utiliza como base se llama **superclase** o clase padre; la nueva clase se llama **subclase** o clase hija.

Tiene sentido cuando la clase hija es un tipo especializado de la clase padre. Por ejemplo, un televisor y un altavoz son tipos de producto: comparten código, nombre y precio, pero cada uno incorpora datos propios.

PHP permite que una clase extienda una única clase. La palabra reservada `extends` declara la relación:

```php
<?php

class Product
{
    public function __construct(
        protected string $code,
        protected string $name,
        protected float $price
    ) {
    }

    public function data(): string
    {
        return $this->name . ' (' . $this->code . '): ' . $this->price . ' €';
    }
}

class TV extends Product
{
    public function __construct(
        string $code,
        string $name,
        float $price,
        private float $inches,
        private string $technology
    ) {
        parent::__construct($code, $name, $price);
    }

    public function data(): string
    {
        return parent::data()
            . ', ' . $this->inches . ' pulgadas'
            . ', tecnología ' . $this->technology;
    }
}

class Speaker extends Product
{
    public function __construct(
        string $code,
        string $name,
        float $price,
        private int $power,
        private float $channels
    ) {
        parent::__construct($code, $name, $price);
    }

    public function data(): string
    {
        return parent::data()
            . ', ' . $this->power . ' W'
            . ', ' . $this->channels . ' canales';
    }
}

$tv = new TV('sm13734', 'Samsung', 759.0, 65, 'QLED');
$soundBar = new Speaker('sn8y', 'LG SoundBar', 300.0, 120, 2.1);

echo $tv->data();
echo $soundBar->data();
```

### Visibilidad y `parent`

- Una propiedad o método `public` es accesible desde cualquier lugar donde el objeto o clase esté disponible.
- Una propiedad o método `protected` es accesible dentro de la clase y sus subclases.
- Una propiedad o método `private` solo es accesible desde la clase que lo declara; una subclase no puede acceder directamente a miembros privados del padre.

En el ejemplo, las propiedades compartidas son `protected`, de modo que las subclases puedan utilizarlas. El constructor de la clase padre se llama con `parent::__construct(...)`; `parent::data()` reutiliza la implementación del método padre.

Cuando una subclase declara un método con el mismo nombre que uno heredado, lo **sobrescribe**. La llamada `$tv->data()` ejecuta la versión de `TV`, que puede ampliar el resultado del padre.

### Consultar la jerarquía

```php
echo get_parent_class($tv); // Product

if (is_subclass_of($tv, Product::class)) {
    echo 'TV es una subclase de Product';
}
```

`get_parent_class()` devuelve la clase padre; `is_subclass_of()` comprueba si un objeto o una clase deriva de otra.

## 2. Sobrecarga y alternativas en PHP

En algunos lenguajes, la **sobrecarga** permite declarar varios métodos con el mismo nombre y distintas listas de parámetros. Al llamar al método, se elige una versión según los argumentos.

PHP no permite definir varios métodos ordinarios con el mismo nombre solo porque reciban parámetros diferentes. Para ofrecer distintas formas de llamada se pueden utilizar, según el caso:

- **Parámetros opcionales con valores por defecto**:

  ```php
  function greet(string $name, string $greeting = 'Hola'): string
  {
      return $greeting . ', ' . $name;
  }

  echo greet('Ada');
  echo greet('Ada', 'Buenos días');
  ```

- **Argumentos con nombre** (PHP 8 o posterior):

  ```php
  function createProduct(string $code, string $name, float $price = 0.0): array
  {
      return ['code' => $code, 'name' => $name, 'price' => $price];
  }

  $product = createProduct(name: 'PS5', code: 'sony-ps5', price: 499.99);
  ```

- **Argumentos variables**, mediante `...`:

  ```php
  function sum(float ...$numbers): float
  {
      return array_sum($numbers);
  }

  echo sum(2, 3);
  echo sum(2, 3, 5, 8);
  ```

Los métodos mágicos `__call()` y `__callStatic()` permiten interceptar llamadas a métodos inaccesibles o inexistentes, pero no equivalen a definir varias firmas. Deben reservarse para diseños que necesiten realmente esa interceptación.

## 3. Clases y métodos abstractos

Una clase declarada con `abstract` no se puede instanciar directamente. Sirve como base común para otras clases.

Un método abstracto declara una operación sin implementar su cuerpo. Las subclases concretas deben implementar los métodos abstractos heredados:

```php
<?php

abstract class Shape
{
    public function __construct(protected string $color)
    {
    }

    abstract public function draw(): void;

    abstract public function getArea(): float;

    public function getColor(): string
    {
        return $this->color;
    }
}

class Square extends Shape
{
    public function __construct(string $color, private float $side)
    {
        parent::__construct($color);
    }

    public function draw(): void
    {
        echo 'Dibujando un cuadrado ' . $this->color;
    }

    public function getArea(): float
    {
        return $this->side ** 2;
    }
}

$square = new Square('azul', 4);
echo $square->getArea(); // 16
$square->draw();
```

`Shape` define qué operaciones debe ofrecer una figura; `Square` aporta las implementaciones concretas. Intentar crear `new Shape('azul')` produce un error porque `Shape` es abstracta.

### Clases y métodos `final`

La palabra `final` impide que una clase se extienda o que un método se sobrescriba:

```php
final class Configuration
{
}

class Car
{
    final public function start(): void
    {
        echo 'Motor encendido';
    }
}
```

Una clase marcada como `final` no puede tener subclases; un método `final` puede heredarse, pero no redefinirse.

## 4. Interfaces

Una **interfaz** declara un contrato: indica qué métodos debe ofrecer una clase, pero no define la implementación de esos métodos. Una clase implementa una interfaz con `implements` y debe proporcionar los métodos exigidos.

```php
<?php

interface ShowData
{
    public function show(): void;
}

class Product
{
    public function __construct(
        protected string $code,
        protected string $name,
        protected float $price
    ) {
    }
}

class Laptop extends Product implements ShowData
{
    public function show(): void
    {
        echo $this->name . ' (' . $this->code . '): ' . $this->price . ' €';
    }
}

$laptop = new Laptop('lt-001', 'Portátil', 899.0);
$laptop->show();
```

Una clase puede implementar más de una interfaz. Esto permite que tipos diferentes compartan un contrato sin obligarlos a heredar de la misma clase base.

## 5. Traits

PHP no permite que una clase herede de varias clases. Un **trait** ofrece una forma de reutilizar métodos en varias clases sin crear una relación de herencia. No se puede instanciar un trait: se incorpora a una clase mediante `use`.

```php
<?php

trait Greetings
{
    public function helloWorld(): void
    {
        echo 'Hola mundo!';
    }

    public function greetingObiWan(): void
    {
        echo 'Hello there!';
    }
}

trait Goodbye
{
    public function goodbye(): void
    {
        echo 'Hasta la vista, baby!';
    }
}

class Jedi
{
    use Greetings;
    use Goodbye;
}

$obiWan = new Jedi();
$obiWan->greetingObiWan();
echo '<br>';
$obiWan->goodbye();
```

Los traits agrupan funcionalidad que puede compartirse entre clases no relacionadas. No sustituyen a una clase padre para modelar una relación de tipo, ni a una interfaz para declarar un contrato.

---

## Resumen

- `extends` crea una subclase; `parent::` permite acceder a métodos o al constructor de la clase padre.
- La herencia de clases en PHP es simple: una clase extiende una sola clase.
- La sobrecarga tradicional de métodos no está disponible; los argumentos opcionales, con nombre y variables permiten diferentes formas de llamada.
- Una clase abstracta define una base que no se instancia directamente; sus métodos abstractos se implementan en las clases concretas.
- Una interfaz declara un contrato que una clase implementa.
- `final` impide extender una clase o sobrescribir un método.
- Los *traits* permiten reutilizar métodos sin establecer una jerarquía de herencia.
