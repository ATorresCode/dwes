# UD05. Arquitectura MVC y separación de lógica

## Objetivos

- Organizar una aplicación web siguiendo una arquitectura MVC básica.
- Separar la lógica de negocio de la presentación.
- Aplicar principios de programación orientada a objetos y modularización.

## Contenidos

- Estructura de carpetas: routes, controllers, services, views, models.
- Middleware y validación.
- Configuración de la aplicación.
- Documentación y pruebas básicas.

## Relación con los RA

- RA5: separación de lógica de negocio y presentación.
- RA4 y RA8: aplicación de estado y generación dinámica con una arquitectura más mantenible.
